1 Hak Akses & Login
Aplikasi memiliki 2 level pengguna dengan hak akses berbeda.

Staff (Tanpa Login)

Dapat mengakses tanpa perlu login:

  • Form Pengajuan — kirim izin, sakit, cuti, tukar shift
  • Cek Tukar Shift — lihat status riwayat tukar shift Anda
  • Rekap Jadwal — lihat siapa bertugas per ruangan
  • Jadwal Lengkap — grid jadwal bulanan

Admin (Perlu Login)

Login dengan email & password yang sudah terdaftar:

  1. Klik ikon user di kiri bawah sidebar, atau tombol Mode Edit di kanan atas
  2. Masukkan email dan password admin
  3. Klik Masuk
  4. Menu admin akan muncul di sidebar (Dashboard, Master Data, dll)
Tips: Sesi login tersimpan di browser, jadi Anda tidak perlu login berulang kali selama belum logout.
2 Fitur untuk Staff
Fitur yang dapat diakses tanpa login.

Form Pengajuan

Mengajukan izin, sakit, cuti, telat, absensi eror, atau tukar shift. Jadwal akan otomatis terupdate setelah pengajuan dikirim.

  1. Ketik nama atau NIP Anda di kolom pencarian, lalu pilih dari daftar
  2. Pilih Jenis Pengajuan (Izin / Sakit / Cuti / Telat / Absensi Eror / Tukar Shift)
  3. Isi tanggal dan detail yang diminta
  4. Tambahkan keterangan (opsional)
  5. Periksa preview di panel kanan
  6. Klik Kirim Pengajuan
Otomatis: Pengajuan Izin/Sakit/Cuti akan langsung mengubah jadwal Anda di bulan terkait dengan kode IZIN / SKT / CT.
Tukar Shift: saat memilih rekan pengganti, sistem akan menampilkan preview pertukaran (kode A lama → baru, kode B lama → baru). Pastikan kedua pihak sudah sepakat sebelum kirim.

Cek Tukar Shift NEW

Melihat status semua pengajuan tukar shift Anda di bulan berjalan (sebagai pengaju maupun pengganti).

  1. Buka menu Cek Tukar Shift
  2. Ketik nama Anda, lalu pilih dari dropdown
  3. Klik Cek Riwayat Tukar Shift
  4. Hasil menampilkan daftar tukar shift yang berhasil: tanggal, pasangan shift, dan kode lama → baru
Data yang ditampilkan hanya untuk bulan berjalan. Untuk bulan lain, hubungi admin.

Rekap Jadwal per Ruangan

  1. Pilih tanggal dengan klik tombol panah atau date picker
  2. Lihat kartu ruangan — klik untuk expand daftar staff bertugas
  3. Ikon ★ menandakan koordinator ruangan
  4. Bagian bawah menampilkan ringkasan staff yang libur/cuti/sakit
  5. Chip berwarna di atas menunjukkan jumlah staf per status (Cuti, Izin, Sakit, DL, dll)

Jadwal Lengkap

Grid bulanan semua staff dengan kode shift per hari.

  • Ganti bulan/tahun dengan tombol panah atau dropdown
  • Gunakan filter: kategori (SHIFT/NON-SHIFT), ruangan, status
  • Ketik di kolom pencarian untuk filter nama staff
  • Kode warna mewakili jenis shift (lihat Bagian 5)
  • Staf non-aktif tidak muncul di daftar pengajuan, tapi tetap ada di data historis
3 Fitur untuk Admin
Fitur khusus admin — perlu login terlebih dahulu.

Dashboard Analytics

Analitik lengkap: KPI, tren, peringkat kehadiran, heatmap, demografi staff, dan lainnya.

  • Filter tahun/bulan di toolbar atas, atau gunakan rentang tanggal khusus
  • Klik grafik untuk membuka mode fullscreen (popup besar)
  • Tekan ESC atau klik area luar untuk menutup popup
  • Klik Export PDF untuk menyimpan laporan dashboard
  • Panel Top/Bottom % Kehadiran punya filter tahun & bulan sendiri
Demografi staff (jenis kelamin, jabatan, umur, masa kerja, status kepegawaian) bersumber dari Master Data Staff.

Rekap Jam Kerja

  1. Pilih tahun dengan panah atas/bawah
  2. Atur rentang tanggal (mulai - akhir) lalu klik Muat
  3. Klik nama staff untuk lihat detail per bulan (termasuk perpindahan ruangan)
  4. Klik ikon printer untuk cetak PDF laporan per staff
  5. Klik Cetak PDF di header untuk cetak semua staff sekaligus

Rekap Kehadiran

  1. Atur periode (tanggal mulai - akhir)
  2. Klik Muat
  3. Klik nama staff untuk detail ketidakhadiran per tanggal
  4. Klik Matrix Bulanan untuk melihat % kehadiran setahun penuh (bisa export PDF landscape)
  5. Klik Cetak PDF untuk laporan per staff (A4) atau semua staff (F4 landscape)
Warna badge % kehadiran: hijau ≥95%, kuning 80–94%, merah <80%.

Master Data Staff

  1. Klik Tambah Staff untuk input data baru
  2. Isi: NIP, Nama, Nama Jadwal, Jabatan, Departemen, Status Kepegawaian, Tanggal Lahir, Tanggal Masuk, Status Keaktifan
  3. Umur & masa kerja akan dihitung otomatis
  4. Gunakan filter Status Kerja untuk menampilkan hanya staff Aktif / Non-Aktif
  5. Klik ikon jam pasir untuk lihat riwayat penempatan, pensil untuk edit, tong sampah untuk hapus
Staff dengan status Non-Aktif tidak akan muncul di form pengajuan staff, namun tetap tersimpan di database untuk keperluan historis.

Riwayat Penempatan

  1. Klik Tambah Penempatan untuk input satu per satu
  2. Klik Import Penempatan untuk bulk input dari Excel
  3. Filter berdasarkan ruangan, peran, atau status (aktif/selesai)
  4. Klik nama staff di Master Data lalu ikon jam pasir untuk melihat timeline penempatannya
Peran yang didukung: Kepala Instalasi, Koordinator, Staff, PIC, Magang, Lainnya. Data ini juga dipakai untuk menghitung Top Staff Multiskill di dashboard.

Daftar Pengajuan

  1. Atur rentang tanggal, jenis pengajuan, dan ruangan
  2. Klik Muat untuk menampilkan data
  3. Klik ikon pensil untuk edit pengajuan (tanggal/keterangan)
  4. Klik ikon tong sampah untuk hapus pengajuan

Mode Edit (Jadwal)

  1. Login sebagai admin
  2. Klik tombol Mode Edit di kanan atas
  3. Anda akan diarahkan ke menu Jadwal Lengkap
  4. Setiap sel jadwal berubah menjadi dropdown — pilih kode baru, atau Kosongkan, atau Hapus Data Ini
  5. Kolom Ruangan juga bisa diedit langsung (ketik lalu Enter/blur)
  6. Tombol 🗑️ di samping nama staff menghapus semua jadwal staff tersebut di bulan berjalan
  7. Perubahan tersimpan otomatis ke database
  8. Klik Keluar Edit untuk menonaktifkan mode edit

Plat Kendaraan NEW

Mencatat kendaraan staff (maksimal 2 kendaraan: motor/mobil) beserta plat nomornya.

  1. Buka menu Plat Kendaraan
  2. Klik Tambah Kendaraan
  3. Ketik nama staff, pilih dari dropdown
  4. Isi jenis & plat kendaraan 1 dan/atau 2
  5. Klik Simpan
  6. Gunakan kolom pencarian untuk mencari berdasarkan nama atau plat

Catatan Admin NEW

Papan informasi per ruangan tentang aplikasi presensi & praktis per shift (Pagi/Midel/Sore/Malam).

  1. Buka menu Catatan Admin
  2. Isi kolom aplikasi presensi & aplikasi praktis untuk tiap ruangan × shift
  3. Klik Simpan Catatan
  4. Data tersimpan otomatis (upsert) — aman jika belum ada baris sebelumnya

Pengaturan

  1. Buka menu Pengaturan (sidebar bawah)
  2. Ubah Label Kode Jadwal (P, TS, S, M, dll)
  3. Atur Jam Kerja per Ruangan (prioritas tertinggi)
  4. Atur Jam Kerja per Kode (SHIFT & NON-SHIFT)
  5. Klik Simpan
4 Import Data dari Excel
Bulk input data dari file Excel tanpa perlu input manual satu per satu.

Import Jadwal (Bulan Baru)

  1. Buka file Excel jadwal bulanan
  2. Blok semua data → Ctrl+C
  3. Buka menu Import Jadwal → Paste (Ctrl+V) di kotak besar
  4. Klik Preview untuk melihat ringkasan
  5. Periksa warning/error jika ada (kode tidak dikenal, tanggal tidak valid, dll)
  6. Klik Import ke Database
Format header tanggal yang didukung: 1 Oktober 2026, 1-Okt-2026, 01/10/2026, atau 2026-10-01.

5 Kode Shift & Formula
Daftar kode shift yang digunakan dalam jadwal.

Kode Shift

KodeKeteranganKategori
PPagiShift
TSMiddleShift
SSiangShift
MMalamShift
LLiburOff
SKTSakitOff
IZINIzinOff
DLDinas LuarOff
CTCuti TahunanOff
CMCuti BersalinOff

Formula % Kehadiran

Piket = P + TS + S + M
Non-Hadir = IZIN + SKT + DL + CT + CM
Hari Kerja Wajib = Piket + Non-Hadir
% Kehadiran = (Piket ÷ Hari Kerja Wajib) × 100%
RentangKategori
≥ 95%Sangat baik
80% – 94%Cukup
< 80%Perlu perhatian
Catatan: Libur (L) tidak dihitung sebagai hari kerja wajib, sehingga tidak menurunkan % kehadiran.
6 Tips & Trik
Fitur tersembunyi dan shortcut yang mempercepat pekerjaan.

⌨️ Keyboard Shortcut

  • ESC — Tutup semua modal yang sedang terbuka
  • Ctrl + F5 — Hard refresh (bersihkan cache)
  • F12 — Buka Console untuk debugging

🎯 Interaksi Cepat

  • Klik kartu ruangan di Rekap Jadwal untuk expand/collapse
  • Klik grafik di Dashboard untuk mode fullscreen
  • Klik nama staff di tabel untuk lihat detail
  • Klik ikon printer untuk cetak laporan PDF per staff
  • Di mode edit, tekan Enter pada kolom ruangan untuk langsung menyimpan

🔍 Pencarian Global

Kotak pencarian di kanan atas berfungsi multi-tab:

  • Mengetik akan otomatis memfilter tabel di tab aktif
  • Bekerja di: Jadwal, Jam Kerja, Kehadiran, Pengajuan

📱 Akses Mobile

  • Sidebar berubah menjadi menu hamburger di kiri atas
  • Navigasi bawah (bottom bar) muncul otomatis: Form, Tukar, Rekap, Jadwal, Dashboard
  • Tabel bisa di-scroll horizontal — kolom Nama tetap sticky
  • Grafik Top/Bottom Kehadiran otomatis berubah jadi list view di layar kecil
7 Pertanyaan Umum (FAQ)
Jawaban untuk pertanyaan yang sering ditanyakan.
Data tidak muncul / kosong?
Kemungkinan penyebab:
  • Belum login sebagai admin (menu tertentu terkunci)
  • Tanggal/periode yang dipilih tidak memiliki data
  • Buka Console (F12) untuk melihat error yang muncul
  • Coba klik tombol Muat ulang di kanan atas
Kenapa pengajuan saya tidak muncul di jadwal?
Cek beberapa hal:
  • Pastikan NIP Anda sudah terdaftar di Master Data Staff dengan status Aktif
  • Pastikan nama di jadwal (nama_jadwal) sesuai dengan yang dipakai di Excel
  • Cek di menu Daftar Pengajuan apakah pengajuan sudah masuk
  • Hubungi admin untuk verifikasi
Bagaimana cara tukar shift dengan rekan?
Isi form Tukar Shift:
  • Pilih nama Anda
  • Pilih jenis: Tukar Shift
  • Isi tanggal tukar
  • Ketik & pilih nama rekan pengganti
  • Sistem akan menampilkan preview pertukaran shift (kode A/B lama → baru)
  • Klik Kirim
Setelah terkirim, cek statusnya di menu Cek Tukar Shift.
Bagaimana cara ganti label kode shift (P, TS, S, M)?
Login sebagai admin → buka Pengaturan (sidebar bawah) → bagian Label Kode Jadwal → ubah teks → Simpan. Label akan berubah di semua tampilan.
Bagaimana cara mengatur jam kerja per ruangan?
Login admin → Pengaturan → bagian Jam Kerja per Ruangan → isi jam untuk tiap kode (P/TS/S/M) di masing-masing ruangan → Simpan. Nilai ini diprioritaskan di atas jam global.
Bagaimana cara mengedit jadwal dengan cepat?
Aktifkan Mode Edit (login admin dulu). Setiap sel jadwal berubah menjadi dropdown:
  • Pilih kode baru → tersimpan otomatis
  • Pilih – Kosongkan untuk menghapus kode (baris tetap ada)
  • Pilih 🗑️ Hapus Data Ini untuk menghapus baris jadwal tanggal tersebut
  • Klik 🗑️ di samping nama untuk hapus semua jadwal staff di bulan itu
Apa itu menu Catatan Admin?
Papan informasi per ruangan tentang aplikasi presensi dan aplikasi praktis untuk setiap shift (Pagi/Midel/Sore/Malam). Berguna sebagai referensi cepat staff di ruangan. Data disimpan sebagai JSON di tabel catatan_farmasi.
Bagaimana cara mencatat plat kendaraan staff?
Buka menu Plat Kendaraan → Tambah Kendaraan → pilih staff → isi jenis & plat kendaraan 1 dan/atau 2 → Simpan. Setiap staff bisa punya maksimal 2 kendaraan.
Grafik tidak rata / tampilan aneh?
Coba:
  • Ctrl + F5 untuk hard refresh
  • Perbesar jendela browser (minimal 900px lebar)
  • Reset zoom browser (Ctrl + 0)
  • Gunakan browser modern (Chrome/Edge/Firefox terbaru)
Apakah data otomatis tersimpan?
Ya. Semua perubahan (edit jadwal, tambah staff, import, catatan, plat kendaraan, dll) langsung tersimpan ke database Supabase. Tidak ada tombol "Save" terpisah kecuali pada halaman Catatan & Pengaturan.
Bagaimana cara export laporan ke PDF?
Di menu yang menyediakan tombol Cetak PDF:
  • Rekap Jam Kerja — cetak per staff (A4) atau semua staff (F4 landscape)
  • Rekap Kehadiran — cetak per staff atau semua staff
  • Matrix Bulanan — cetak tabel matrix % kehadiran (landscape)
  • Dashboard — export seluruh dashboard ke PDF (portrait)
Apa perbedaan staff Aktif dan Non-Aktif?
Staff Non-Aktif (misalnya resign/keluar):
  • Tidak muncul di dropdown form pengajuan staff
  • Tetap muncul di tabel Master Data (bisa difilter)
  • Data historis jadwal, kehadiran, dan penempatannya tetap tersimpan
Siapa yang bisa mengakses menu admin?
Hanya user yang email-nya terdaftar di tabel admin_users. Jika login berhasil tapi menu admin tidak muncul, hubungi pengembang untuk mendaftarkan akun Anda.
